### markdown学习

#### 换行，分段
首先第一个就是分段必须要以空行为分段Markdown不认Tab
或者啊，你也可以在行尾加**两个空格**再回车，这样也行
#### 标题
这很简单啊 一级标题就是
```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```
#### 加粗
```
**加粗**
```
你直接** **然后写你想写的内容就行了** **
#### 斜体
```
*文字*
```
这样用的*Abandon*
*Banana*
*123阿伯词的*
#### 删除线
```
~~文字~~
```
