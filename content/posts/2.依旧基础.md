# Stack和Heap


## Stack

Stack可以复制数据相当于开辟新的空间

就直接

```rust
let a = 1;
let b = a;
```

栈内存（Stack）
┌───────┐
│   a   │ → 1   ← 独立空间
├───────┤
│   b   │ → 1   ← 另一个独立空间（a 的副本）
└───────┘

## Heap

heap相当于相当于把所有权从a转到b从而a变成未定义的样式

```rust
let a = Box::new(1);  // Box 在栈，数据在堆
let b = a;            // Move：不能 Copy，所有权转移
//此时a为空 b为1的地址
```

栈内存              堆内存
┌───────┐          ┌───┐
│   a   │ →  ???   │ 1 │   ← a 现在无效（悬垂/未初始化）
├───────┤          └───┘
│   b   │ ────────→│   │   ← b 独占堆数据所有权
└───────┘

**那么如何才能避免数据的移动呢？**

哎！

直接.clone()方法进行克隆

```rust
let a = Box::new(1);
let b = a.clone();
```

就可以啦！

**当然了！你也可以通过引用**

**but！** 引用是没有所有权的指针

```rust
let a = String::from("hello");
let b = String::from("world");
greet(&a,&b);


fn greet(g1:&String,g2:&String){}
```

这样greet之后 a b依旧存在！
