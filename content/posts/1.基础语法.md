## 循环表达

### loop

#### 1.作为结果值返回

```rust
fn main() {
    let mut temp = 0;
    let a = loop
    {
        temp+=1;
        if temp == 10
        {
            break temp * 2;
        }
    };
}
```

#### 2.作为while(1)用

```rust
fn main(){
    let mut a = 0;
    loop{
        a+=1;
        if a == 10{
            break;
        }
    }
}
```

#### 3.小goto

```rust
fn main(){
    let mut count = 0;
    'counting_up:loop{//把这个loop打上标签
        println!("count = {count}");
        let mut remaining = 10;

        loop{
            println!("remaining = {remaining}");
            if remaining == 9{
                break;
            }
            if count == 2{
                break 'counting_up;//用标签的方式结束
            }
            remaining -= 1;
        }
        count += 1;
    }
    println!("End count = {count}");
} //直接跳到外层循环 
```
